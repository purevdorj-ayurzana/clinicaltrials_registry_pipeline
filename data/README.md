# Study inputs

- [classifier](classifier): the selected publications and their ClinicalTrials.gov identifiers, along with primary endpoint classification (positive, negative, or unclear).
- [registry](registry): compressed ClinicalTrials.gov data, including current records, all 54,631 historical versions and their version lists, download details, and links between the original NCT identifiers and the corresponding trial records.
- [semantic_assessment](semantic_assessment): one saved assessment per
  trial, together with the GPT model settings used to generate it.
